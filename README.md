## دربارهٔ هرمز

هوش هرمز پروژه‌ای مستقل برای پیوند فناوری با نیازهای واقعی انسان است. هدف آن فراهم‌کردن بستری شفاف برای راهنمایی، ارتباط، معرفی خدمات و کسب‌وکارها و پیگیری درخواست‌هاست.

**شعار:** «نوا کمک می‌کند، هرمز هماهنگ می‌کند، انسان تصمیم می‌گیرد.»

**اصل بنیادین:** «دست گرفتن همدیگه؛ کمک کردن بدون سوءاستفاده.»

## وضعیت و شفافیت

پروژه در حال توسعه و آزمون است. وجود یک صفحه یا API به‌تنهایی به معنی آماده‌بودن همهٔ خدمات، رزرو، پرداخت یا تأیید درخواست نیست. هر قابلیت فقط زمانی عملیاتی محسوب می‌شود که در محیط واقعی آزموده و نتیجهٔ آن تأیید شده باشد.

- درگاه عمومی، نقطهٔ ورود اصلی کاربران است.
- بک‌اند با مسیر سلامت و APIهای نوا ارائه می‌شود.
- ثبت درخواست، پیگیری، پرداخت و سایر خدمات باید بر اساس وضعیت واقعی هر بخش معرفی شوند؛ هیچ درخواست یا پرداختی بدون تأیید سامانه قطعی تلقی نمی‌شود.
- امنیت، حریم خصوصی، شفافیت و تصمیم نهایی انسان در اولویت هستند.

## همکاری

از توسعه‌دهندگان، متخصصان هوش مصنوعی، امنیت، طراحی و صاحبان تجربه برای همکاری مسئولانه دعوت می‌کنیم. هر همکاری باید بر پایهٔ توافق روشن، احترام متقابل و شفافیت دربارهٔ مسئولیت‌ها و حقوق طرفین باشد.
